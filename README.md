# L3dispersion
Reproduction des figures d'un article scientifique https://pubmed.ncbi.nlm.nih.gov/27044655/ en écrivant un code Pyhton d'après les informations fournies dans l'article, dans le cadre d'une UE de L3 en groupes de trois élèves.

Membre du groupe : Maïwen Demeulle; Alexandre Pradignac; Thibaud Civetta

L'article traite le sujet de la dispersion spatiale des graines d'une plante amphicarpe en introduisant une variabilité dans l'environnement.
